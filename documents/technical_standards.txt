มาตรฐานกันน้ำ IP Rating (Ingress Protection) — คู่มือสำหรับลูกค้าร้านอุปกรณ์เสริมมือถือ

IP Rating คือมาตรฐานสากลที่บอกว่าอุปกรณ์อิเล็กทรоникทน "ฝุ่น" และ "น้ำ" ได้แค่ไหน ตัวเลขหลัง IP มีความหมายแยกกัน เช่น IPX4, IP67, IP68

IPX4 (กันละอองน้ำ / Splash Resistant)
- ทดสอบด้วยการพ่นละอองน้ำจากทุกทิศเป็นเวลา 10 นาที
- เปรียบเทียบให้เห็นภาพ: ใส่ออกกำลังกายแล้วเหงื่อไหล หรือเดินกลางแจ้งแล้วเจอฝนโปรยๆ หูฟัง/อุปกรณ์ระดับ IPX4 เอาอยู่สบาย
- ข้อจำกัด: ห้ามจุ่มน้ำ ห้ามใส่ลงอ่างน้ำ ห้ามล้างใต้ก๊อกน้ำแรงๆ
- เหมาะกับ: หูฟังออกกำลังกาย ไลฟ์สไตล์ประจำวัน การใช้งานกลางแจ้งที่มีฝนเบาๆ

IPX5 / IPX6 (กันน้ำฉีด)
- IPX5: ทนน้ำฉีดจากหัวฉีดได้ในระดับหนึ่ง
- IPX6: ทนน้ำฉีดแรงกว่า IPX5
- เปรียบเทียบ: ฝนตกหนักหรือน้ำกระเซ็นจากรถที่วิ่งผ่าน — ยังไม่ใช่การจุ่มน้ำ

IPX7 (กันการจุ่มน้ำชั่วคราว)
- จุ่มในน้ำนิ่งลึกประมาณ 1 เมตร เป็นเวลา 30 นาที (ตามเงื่อนไขการทดสอบมาตรฐาน)
- เปรียบเทียบ: ตกลงไปในสระว่ายน้ำตื้นๆ หรือโดนน้ำท่วมข้อมือชั่วคราว — มักรอด แต่ไม่ได้ออกแบบให้ว่ายน้ำเป็นเวลานาน
- หมายเหตุ: มาตรฐานทดสอบในห้องแล็บ การใช้งานจริง (น้ำเค็ม แรงดัน อุณหภูมิ) อาจลดประสิทธิภาพลง

IP68 (กันฝุ่น + กันน้ำเข้มข้น)
- กันฝุ่นเข้าสู่ตัวเครื่องได้จริงจัง (dust-tight)
- กันน้ำได้ลึกและนานกว่า IPX7 ตามที่ผู้ผลิตระบุ (เช่น 1.5–2 เมตร 30 นาที)
- เปรียบเทียบ: ใช้กลางฝนหนัก ทนเหงื่อ/ฝุ่นในสภาพแวดล้อมหนัก บางรุ่นรองรับการแช่น้ำตามสเปกผู้ผลิต
- ข้อจำกัด: ยังไม่ควรดำน้ำลึกหรือใช้ในน้ำเค็มโดยไม่ตรวจสอบคู่มือรุ่นนั้นๆ

คำแนะนำเวลาขายให้ลูกค้า
- ถามการใช้งานจริง: ออกกำลังกาย / กลางแจ้ง / ว่ายน้ำ / ใช้ในออฟฟิศ
- อธิบายด้วย analogy ชีวิตประจำวัน ไม่ใช่แค่ตัวเลข IP
- ถ้าสินค้าระบุ IP ในคำอธิบาย ให้อ้างอิงสเปกนั้น + อธิบายมาตรฐานทั่วไปเสริม
- ห้ามอ้างว่ากันน้ำได้ถ้าสินค้าไม่ได้ระบุ IP หรือไม่มีข้อมูลยืนยัน

สเปก Bluetooth พื้นฐาน (หูฟัง / ลำโพง / อุปกรณ์เสริม)

Bluetooth 5.0 / 5.1 / 5.2 / 5.3
- รุ่นใหม่กว่ามักมีระยะเชื่อมต่อไกลขึ้น กินแบตน้อยลง และเสถียรกว่าในงานไร้สาย
- Bluetooth 5.x รองรับ LE Audio ในบางรุ่น (เสียงคุณภาพดีขึ้นผ่าน LC3 codec)

Codec ที่พบบ่อย
- SBC: codec มาตรฐานทุกอุปกรณ์ คุณภาพพอใช้
- AAC: มักใช้กับ iPhone / iPad คุณภาพดีกว่า SBC
- aptX / aptX HD / LDAC: มักพบใน Android / หูฟัง hi-fi คุณภาพเสียงสูงกว่า ต้องทั้งมือถือและหูฟังรองรับ

คำแนะนำเวลาขาย
- iPhone ลูกค้า: เน้น AAC compatibility
- Android ลูกค้า: ถามว่าต้องการ aptX/LDAC หรือไม่
- อธิบายว่า codec ที่ดี = เสียงคมชัด latency ต่ำกว่า (สำคัญกับเกม/วิดีโอ)

Latency (ความหน่วง)
- หูฟังทั่วไป ~150–300 ms — ดูวิดีโออาจรู้สึกเสียงไม่ตรงปาก
- Gaming mode / Low latency mode ลดเหลือ ~60–80 ms — เหมาะเกมและดูหนัง
